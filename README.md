# 海岛打水漂 Stone Skipping (Godot 4.7.2) — v12 倒影边缘不再拉伸 + 原地转身 + 手机性能 + 细叶灌木 + 投掷左臂 + 火把 + iPhone 安全区

低多边形热带海岛小游戏。场景、道具由 GDScript 代码生成；小男孩由 Blender 脚本（`art/boy/`）建模、绑定骨骼、制作动画后导出 glTF；水面为自写着色器，所有声音均为代码合成。
渲染器：Compatibility（gl_compatibility），Web 导出为单线程版本（无需 SharedArrayBuffer / 跨域隔离头）。

## v12 改动
在线试玩：<https://dodosann2024.github.io/stone-skipping-godot/>（导出文件改名为 `game_v12.*`，保留 iOS 声音解锁的 head_include，另加安全区脚本）。截图与视频见 `screenshots/v12/`。

### 1. 倒影在屏幕边缘不再拉伸（`reflection.gd`、`shaders/water.gdshader`）
- **保护带（overscan）**：镜像相机比主相机每边多看 10%（`GUARD = 0.1`，视场角按 `tan` 放大 1.2 倍），水面着色器把屏幕坐标按 `0.5 + (uv - 0.5) / 1.2` 映射进中间那块，所以被波浪偏移推到屏幕外的采样仍然落在真实画面上。
- **偏移限幅**：波浪扭曲的偏移长度限制在保护带的 80% 以内，任何角度都不会采样到反射图外面。
- **兜底**：采样点离反射图边缘不到 1.2% 时淡到天空色（夜里是夜空渐变），不会出现拉伸的条纹。
- **像素预算不变**：保护带和 v11 共用同样的反射分辨率（137×295 @ 390×844），手机上不多花填充率，只是略软一点。
- 结果：用着色器调试遮罩统计“采样落在反射图外”的水面像素，v11 每张 1.1%~1.6%（最差 3.5%），v12 为 0%。机位为码头 360° 每 45° 一张、拉近 / 拉远、从海上低角度，白天和夜晚各一套。图：`refl_edge_day_before_after.png`、`refl_edge_night_before_after.png`（左右边缘放大，before = v11）、`refl_edge_debug_mask_day_portrait.png`、`70_day_yaw270.png`、`70_night_yaw180.png`。

### 2. 急转弯：原地转身代替快速小碎步（`boy.gd`、`main.gd`）
- 站着或慢走时摇杆一下甩到身后（偏差 > 63°、速度 < 0.4 m/s，或偏差 > 115°、速度 < 0.9 m/s），进入**原地转身**：身体按限定转速转过去（`Boy.spot_turn`），两脚交替小步踩到新朝向（落点锚定在世界里），重心先移到支撑脚（`hip_shift`），头先转、胸再转、髋最后（`_lead_turn`）。转完再起步。
- 快速小碎步只在真的需要时才出现：脚离锁定点超过 22 cm、腿伸直到够不着，或者比动画多伸出 5% 以上且偏差超过 10 cm；其余情况把过伸的腿每帧最多 2.5 mm 地收回来（`_ease_overreach`）。
- 结果（`--selftest`，同一套操作）：快速小碎步 v11 30 fps 4 次 / 20 fps 9 次 → v12 6 / 6 次（剩下的每次脚都偏 12~26 cm 或腿够不着）。游戏里 180° 甩摇杆：v11 0.23 秒甩过去、6 次小碎步 → v12 1.0 秒、4 个交替的原地步、0 次小碎步、身体漂移 0.0 cm。支撑脚最大滑动 30 fps 2.1 mm、20 fps 2.6 mm（< 5 mm）。新的自检 `SELFTEST turn on the spot`。视频：`turn_on_the_spot.mp4`（码头侧面：180° / 90° / 135° / 走着掉头；0.4 倍慢放；游戏视角）。

### 4. 灌木和草丛（`island.gd`、`shaders/leaf.gdshader`、`tools/make_leaves.py`）

- 叶簇之间露出细枝（每片叶团两根分叉的枝条）。
- LOD：62 m 以外换成稀疏的大叶簇（三分之一的数量）；阴影用单独的稀疏集合；反射里不画。
- 草丛：每簇改为 3 段弯曲、渐细的细长草叶，根部深、叶尖浅。
- 碰撞体和布局与 v11 完全一样（随机数序列不变）。软件渲染下帧率 11.2 → 10.3 fps。图：`bush_closeup_before_after.png`、`bush_side_before_after.png`、`grass_low_before_after.png`、`bush_game_view_iphone_before_after.png`、`83_bush_game_view.png`、`p_83_bush_game_view.png`。

## v11 改动
在线试玩：<https://dodosann2024.github.io/stone-skipping-godot/>（导出文件改名为 `game_v11.*`，保留 iOS 声音解锁的 head_include）。截图与视频见 `screenshots/v11/`。

### 1. 走 ↔ 跑切换、转弯时支撑脚不再滑动（`boy.gd`）
- **步态相位同步**：走、跑两个片段共用一个归一化相位。加载时对两个片段各采样 64 个相位点，记下每只脚脚跟 / 前脚掌的位置（`_build_gait_tables`）。走跑混合权重变化的那几帧里，相位不再按固定速度前进，而是解出一个相位增量，让“混合后”的支撑脚正好向后移动身体前进的距离（`_stance_advance`），所以步幅和播放速度始终和移动速度匹配。
- **支撑脚锁定 + 两骨骼 IK**（`_foot_lock`、`_leg_ik`）：脚着地时记住它在世界里的接触点（脚跟、前脚掌或两者中点），之后每帧算出一个刚体修正（水平偏移 + 绕踝的转角），用解析的两骨骼 IK 把大腿 / 小腿摆到修正后的位置，膝盖保持在原动画的腿平面里。脚抬起后修正在约 0.1 秒内平滑衰减为 0。
  - 只有脚跟和脚尖都着地时才锁朝向；转角超过 0.45 rad 时改为以前脚掌为轴转（脚跟略抬起），不会出现脚扭在地上的情况。
  - 急转（摇杆一甩，转速可到约 10 rad/s）时修正超过 15 cm 就补一个 0.16 秒的快速小碎步（抬脚 6 cm，落到动画位置），而不是硬拖着脚。
- **转身**（`_plant_turn`）：可见转速上限 12 rad/s；单脚支撑时以支撑脚为轴、双脚支撑时以两脚中点为轴转身。
- **测量与自检**：`dev/gait_probe.gd` 用固定的一段操作驱动小男孩：起步、直走、走→跑、直跑、跑着转弯、跑→走、走着转弯、停下、走 / 跑之字形（按游戏里摇杆转向的速度）、跑着急停。每帧量“着地的脚底接触点”在世界里的移动距离。`--selftest` 在 30 fps 和 20 fps 下各跑一遍，任一帧超过 5 mm 即失败。
- 结果（每帧最大滑动，mm，30 fps；v10 为同一套操作在 v10 代码上的结果）：

| 片段 | v10 | v11 |
|---|---|---|
| 起步 | 14.4 | 0.8 |
| 直走 | 3.4 | 1.8 |
| 走 → 跑 | 29.8 | 1.5 |
| 直跑 | 3.7 | 0.5 |
| 跑着转弯 1.3 rad/s | 9.3 | 0.5 |
| 跑 → 走 | 40.8 | 0.2 |
| 走着转弯 1.6 rad/s | 14.9 | 1.7 |
| 停下 → 待机 | 6.5 | 0.4 |
| 走之字形（游戏转向） | 140.1 | 1.2 |
| 跑之字形（游戏转向） | 181.6 | 1.0 |
| 跑着急停 | 7.4 | 0.8 |

  60 fps 最大 0.8 mm，20 fps 最大 4.0 mm（跑着转弯）。只用相位同步、不用脚锁定（`--nolock`）时跑 → 走仍有 8.6 mm。曲线见 `foot_slide_graph.png`。
- **脚印位置**：原来在脚步声（脚跟刚触地）那一刻盖脚印，脚随后放平、前移，脚印和脚实际停住的位置差约 4~6 cm（中位数）。现在在脚跟和前脚掌都着地的那一帧盖（`Boy.foot_flat` 信号），快速小碎步落地后再盖一个新的。`--selftest` 检查脚印数量（40 步 39 个）和脚印位置在之后 0.06 秒内的偏移（30 fps 3.2 mm，60 fps 3.4 mm；20 fps 跑步时脚跟已开始抬起，14 mm）。

### 2. 水面实时倒影（白天和夜晚）+ 夜晚灯光倒影（`reflection.gd`、`shaders/water.gdshader`）
- **平面反射**：一个低分辨率 SubViewport 共用同一个场景，用主相机关于水面（y = 0）镜像后的相机渲染（窗口像素 × 0.35，长边最多 480 px）。水面着色器按屏幕坐标采样（上下翻转），用波浪法线偏移制造扭曲，按菲涅尔（Schlick）加权混合；浪花处不反射。在 gl_compatibility / WebGL2 上可用，不依赖屏幕空间反射。
  - 水面和蹚水波纹放在渲染层 2，反射相机不渲染它们；地形、静物、植物、小男孩的着色器在反射这一遍里丢掉水面以下的部分。
  - 反射相机看到的是一个**不投影的太阳副本**（灯光也按相机层剔除），所以平行光阴影图不会再渲染一遍。
  - 夜里倒影能看到岛、椰子树、码头、小屋的灯窗、路灯和灯塔；打开倒影后不再用 v10 的近似夜空，星光闪点保留。
- **夜晚灯光拉长倒影**：篝火、灯塔和码头 / 小屋 / 路边的灯（共 12 个）在水面上形成一条向观察者方向拉长、随波闪烁的光带（三级 Blinn 高光 + 闪烁网格）。
- **帧率与自动降级**：连续两个 2 秒窗口平均低于 26 fps 时自动降一级：先降到 0.25 倍、隔帧更新，再不行就关闭倒影（回到 v10 的近似夜空）。网址参数 `?refl=0|low|1` 强制关闭 / 低 / 高，`?fps=1` 在左上角显示帧率和倒影档位，`?night=1` 直接进入夜晚（桌面版用 `--refl=` / `--fps` / `--night`）。
- 测量（390×844，桌面版，llvmpipe 软件渲染）：

| 设置 | fps | draw calls（主画面 + 倒影） |
|---|---|---|
| 关闭倒影 | 12.7 | 47 + 0 |
| 倒影（高） | 10.5 | 47 + 18 |
| 倒影（第一版，未去掉第二遍阴影） | 7.5 | 47 + 40 |

  软件渲染下倒影约增加 20% 的帧时间。无头 Chrome（SwiftShader）里开 / 关倒影都是 7.5 fps（被 CPU 渲染限制，测不出差别）。这里没有真机，**没有在 iPhone 上实测**；倒影只多 18 个 draw call，渲染分辨率约为主画面的 4%，在 iPhone 上可以用 `?fps=1` 查看，跟不上时会自动降级。

### 3. 篝火木头周围的地形（`island.gd`）
- 篝火空地：火堆 3 m 内，高于火堆的地面按 0.25 压向火堆高度，再在 6 m 内平滑过渡回原地形（低于火堆的部分不动，沙滩和浪花带完全不变）。
- 每根木头下面的平地：木头轴线两侧 0.42 m 内水平，再用 1.9 m 的 smoothstep 过渡（v10 是 0.75 m / 1.4 m 的直线过渡）。火堆、围石、柴堆改为跟随过渡后的地面。
- 篝火周围加了一块 0.25 m 的细分地形网格（12×12 m），网格能准确贴合过渡曲线；细分块边界上的顶点按粗网格插值，不会裂缝。

## v10 改动

### 1. 投掷时手臂不再穿过身体（`clips.throw_stand` / `clips.throw_crouch`，Blender 重新烘焙）
- 动作路线不变：右臂从身后来，向前远远送出、出手，再横扫到身体左侧，然后收手回待机。
- 横扫时上身明显左转（骨盆和胸椎的转角加大，头跟着看向出手方向），给手臂让出空间。手臂的路线是在胸前、绕着躯干走：肘部弯曲，手和前臂始终在胸、腹、髋、背心之外，也不碰另一只手臂。
- 手的目标点在“胸腔坐标系”里给出（`_chest_hand`），所以躯干转多少，手臂就跟着绕多少，不会因为转身而插进身体。
- 半蹲投掷同样处理：低位横扫、身体前倾。左手（平衡手）的位置也重新调过。
- 欢呼（cheer）和失误（oops）的反应动作也改了：举手、放手时手从身体两侧走，不再从脸前、胸前穿过去，垂下的手也不插进大腿。
- 新的自动检查（`dev/arm_clearance.gd`，与 Blender 端的 `art/boy/clearance.py` 是同一个模型）：从蒙皮网格量出躯干每一段的截面轮廓（`boy/torso_profile.json`），逐帧（1/30 秒）采样右手、手指、手腕、前臂、肘、上臂和左臂，计算它们到躯干表面、到另一只手臂、到大腿的距离。`--selftest` 覆盖站立投掷、半蹲投掷（含收手）、欢呼、失误、待机、走、跑，任何一帧低于阈值就失败。

### 2. 走路 / 跑步的上半身（`clips.Gait.pose`）
- 手臂与脚相反方向摆（左脚在前 = 右手在前，原有的 selftest 检查仍通过，相关系数 -0.95 / -0.82）。摆动主要来自肩关节，稍有滞后；走路时肘部微弯，跑步时肘部弯到约 70~90° 并随摆动略开合；手放松半握，手腕自然下垂。
- 肩部与骨盆反向小幅转动（走 ±0.135 / 跑 ±0.24 rad 的胸椎转角对 ±0.075 / ±0.10 的骨盆转角）。
- 身体上下起伏与步伐同步：脚着地时最低、支撑中期最高（幅度：走约 ±1.2 cm、跑约 ±2.4 cm）；左右轻微重心转移；上身前倾随速度增加（走一点点，跑更明显）。
- 头部稳定：抵消胸部的转动和侧倾，只留很小的点头。
- 走 / 跑之间的混合更快（约 0.2 秒），待机↔走的权重用平滑曲线；转弯时上身向内侧轻微倾斜（倾角按速度 × 转速计算，最多约 6°），只倾上身、不动腿，所以脚不滑。

### 3. 以前列出的已知问题
- **夜里水面反射白天的天空**：引擎的天空反射（radiance）在这个渲染器里不会随天空更新，所以夜里把水面和湿沙的引擎反射关掉，改为在水面着色器里自己“反射”夜空：按反射方向取夜空的蓝色渐变（菲涅尔加权），加上月亮的光晕和被波浪打碎的月亮倒影、零星的星光闪点，与 `night_sky.gdshader` 的月亮方向一致。
- **水下的腿看起来太短**：原来把水下的顶点抬高约 22%（模拟视深），但海底没有一起抬高，所以腿被压短、脚像浮在沙上。现在只保留很小的抬升（6%，最多 2.5 cm）和晃动，腿长看起来正常，脚踩在沙上。
- **浪花偶尔出现一段整齐的白边**：原因是浪潮周期用 `fract()` 计算，周期回绕的那条线两侧泡沫一边满、一边无，形成一条直边。现在所有泡沫项在周期两端都过渡到 0（沙滩冲刷泡沫、远处的碎浪带、浅水漂浮泡沫），回绕处是连续的。
- **网页版夜晚比桌面版亮**：在同一视角、同一分辨率（390×844）下对比，夜晚完全过渡后网页版和桌面版的平均亮度相差不到 2%（RGB 均值 47.6/52.8/39.7 对 48.4/53.8/40.2，见 `cmp_web_vs_desktop_night.png`）。之前看到的“更亮”来自无头浏览器（软件渲染，不到 1 帧/秒）截图时夜晚过渡还没走完。
- **夜晚模式不保存**：现在保存在 `user://best.cfg`（网页版是浏览器的 IndexedDB），重新打开游戏会直接是夜晚；演示 / 自测模式不读也不写。网页版已验证：切到夜晚 → 刷新页面 → 仍是夜晚。
- **坐在篝火边的木头上随坡倾斜**：三根木头所在的地面有明显坡度（脚下的地面高低差可达 ±20 cm，木头两端 ±30 cm）。现在每根木头下面有一块平整的沙地（木头轴线 0.75 m 内水平，1.4 m 内平滑过渡回原地形），地形网格、碰撞高度、物体摆放都用同一个高度函数。`--selftest` 检查每根木头两侧脚下和两端的地面高差（现在都是 0.000 m）。
- **白天篝火的光太弱**：白天点光源亮度提高到约 3（原来 1.55），范围缩短到 5 m，石头、木头和周围的沙地 / 草地在白天也能看到暖色的光；夜晚基本不变（约 3.4，范围 9.5 m）。
- **约 1 cm 的脚底滑动**：
  - 脚跟抬起时绕前脚掌关节本身转动（原来的支点偏了 1.8 cm，抬脚跟时脚趾会往后蹭）。
  - 摆动腿落地前的速度和身体速度对上（落地时脚相对地面速度为 0）；跑步循环烘焙时长与游戏里的周期完全一致（原来差 2%，每步累积滑动）。
  - 转向时：两脚都着地时先不转身，单脚支撑时以支撑脚为轴转；松开摇杆后先把这一步走完再停下（最多 0.6 秒，低帧率时也能正确停下）。
  - 测量方法改成量脚底真正接触地面的点（脚跟 / 前脚掌），而不是踝关节。结果（每帧滑动，30 fps）：直线走最大 3.4 mm / 平均 0.4 mm，直线跑最大 3.7 / 1.2 mm，停下到待机最大 7.9 / 0.5 mm；原来直线走路每步约 3~5 cm 的脚跟蹭动、停下时一帧约 4 cm。

- 出手时间与出手高度不变（`--sim`：站立 0.51 m，半蹲 0.23 m），同力度 / 角度的弹跳次数与 v7 基本一致。

### 2. 实体碰撞：不再穿过东西
- `island.gd` 为每个实体道具登记“走路墙”：圆柱（椰子树、石头、灯塔、篝火、木桩、灯柱、火把、灌木……）、胶囊（坐木、小船、吊床、护栏绳、渔网、冲浪板……）、旋转长方体（长椅、躺椅、木箱、钓鱼小屋及台阶、码头下方）。每面墙带高度范围，所以能在码头上走、在浅水里蹚水，但不能从码头下面穿过去。

## v7 改动
在线试玩：<https://dodosann2024.github.io/stone-skipping-godot/>（导出文件改名为 `game_v7.*`）。截图与视频见 `screenshots/v7/`。

### 1. 修复走路 / 跑步顺拐
- 原因在 Blender 烘焙（`art/boy/clips.py` 的 `Gait.pose`）：左脚在相位 0 落地向前，而左臂的摆动 `A·cos(相位)` 也在相位 0 最向前，于是同侧手脚一起前后摆。骨骼轴向、左右镜像和 Godot 播放都没有问题（骨盆转动与肩膀反向转动方向本来就是对的）。
- 现在手臂与对侧腿同步（左脚向前 = 右手向前），并略微滞后于腿。
- 数值验证：沿着小男孩朝向，相对骨盆采样一个步态周期，计算前后位移的相关系数。走路：左脚~左手 −0.94、左脚~右手 +0.95；跑步：−0.89 / +0.89；髋部（左−右）~左脚 +0.89，肩部（左−右）~左脚 −0.90。
- 这个检查已加入 `--selftest`（通过真实的 AnimationTree 混合器读取导入后的骨骼，所以导入 / 轴向出错也能发现）。用 v6 的模型运行会失败（同侧相关 +0.76 / +0.99）。

### 2. 侧手打水漂投掷（站立 / 半蹲，`clips.throw_stand` / `clips.throw_crouch`）
- 蓄力（按力度 0–1 拖动）：重心压到后脚（右脚），髋和上身向后拧，持石的手低低地拉到身后，左手指向目标，前脚跟抬起。
- 出手：前脚向前跨一小步并踩实 → 髋先转开 → 上身随后 → 手臂低位侧甩，前臂几乎平行于水面，手腕甩出；出手时间和以前一样（开始挥臂后 0.15 s），出手高度几乎不变（站立 0.48 m / 半蹲 0.22 m，v6 为 0.49 / 0.23）。
- 随挥：手臂从身体前方甩到左髋，上身继续转，后脚跟抬起转动；然后后脚上步、前脚收回，平滑回到待机姿势（不再停在伸直手臂的姿势）。半蹲版本随挥后先把重心移到前脚、撑起站直，再收脚回到待机。
- `--sim` 投掷结果与 v6 基本一致（同力度 / 角度的弹跳次数相差最多 1 次）；`--selftest` 检查每次投掷后都会回到待机。

### 3. 沙滩脚印被浪冲掉
- 在沙地上（不在水里、码头、草地，也不在正被浪覆盖的湿沙上）每一步都留下人字拖脚印：凹下去的鞋底更暗，边缘有一圈微微隆起的亮边。最多同时保留 48 个，30 秒后开始变淡，75 秒完全消失。
- 浪冲：`island.gd` 里用 GDScript 复刻了地形着色器的浪线公式（`sea_y`、`wash_cycle`、`runup`、噪声），每帧检查每个脚印，浪的水膜一碰到就记下时间，着色器在 0.7 秒内把它抹平——和画面上的白色浪线同步。
- 性能：着色器只在脚印的包围盒里循环，其他像素不付出代价。

### 4. 其他小修
- 待机时双手离身体稍远一点，不再插进外翻的短裤裤腿里（所有动作都从这个姿势开始 / 结束，所以一起生效）。
- 欢呼 / 失望动作还没播完就开始蓄力时，以前会直接跳到投掷准备姿势；现在 0.3 秒交叉淡入。半蹲时跪下过程约 0.3 秒，不再“瞬间蹲下”。

### 5. 截图与视频（`screenshots/v7/`）
- `00_gait_contralateral_plot.png`：游戏内实测的一个步态周期里脚 / 手的前后位移（左脚与右手同相）；`gait_side.mp4` / `00_gait_side_strip.png`：侧面走 / 跑。
- `throw_stand_crouch.mp4`、`00_throw_stand_strip.png`、`00_throw_crouch_strip.png`：站立和半蹲投掷（右前方近景），以及游戏相机下的一次投掷。
- `footprints_wash.mp4`、`00_footprints_wash_strip.png`：沿水线走出 U 形脚印，浪冲上来时下面的脚印被抹掉，上面干沙上的保留。

### 已知问题
- 浪线判断是按每个脚印的中心点做的：浪刚好只漫过脚印一半时，整只脚印会一起淡出。

## v4 改动
### 1. 声音（iPhone 没声音）
- 最可能的原因：iOS Safari 的 Web Audio 默认使用 “ambient” 音频会话，**iPhone 侧边静音开关打开时网页游戏完全没有声音**（音乐 App 不受影响，所以很容易误以为是游戏坏了）。另一个次要原因：iOS 只把 `touchend` / `click` 算作“用户激活”，`touchstart` 时恢复 AudioContext 可能无效。
- 修复（`export_presets.cfg` 的 `html/head_include`，源码见 `web/audio_unlock.js`）：
  - 在每次 `touchend / pointerup / mouseup / click / keydown`（捕获阶段）以及页面切回前台（`visibilitychange` / `pageshow`）时：
    - 设置 `navigator.audioSession.type = 'playback'`（Safari 17+，让网页声音不受静音开关影响）；
    - 旧版 iOS 没有 audioSession 时，在同一手势里播放一个循环的静音 `<audio playsinline>`（把会话切到 playback）；
    - 对页面里所有 AudioContext（挂钩构造函数收集）调用 `resume()`，并播放一个 1 采样的空 buffer。
  - 「点击开始」改为**松手时**开始（touchend），开始后先响一声短“叮”，确认有声音。
  - 网页版开始后显示可关闭的提示：「没声音？请关闭 iPhone 侧边静音开关并调高音量」。
  - 之后每次点屏幕都会再尝试恢复音频（防止来电 / 切 App 后被系统挂起）。
- 音频文件仍为 OGG：Godot Web 在 wasm 里自己解码 OGG 再交给 Web Audio 播放，不依赖 Safari 的 OGG 支持。

### 2. 小男孩新形象（`boy_mesh.gd`）
- 去掉粉色腮红、圆脸、小嘴、齐耳短发：改为略方的脸型与下颌、草帽下露出刺刺的短碎发和鬓角、粗眉、大而有高光的眼睛、小鼻子、露牙的大笑、雀斑、左脸一张创可贴、晒黑的皮肤。
- 表情：待机微笑；蓄力 / 出手咬牙使劲；欢呼时张嘴大笑；失手时“哦”；睡觉闭眼；晒太阳戴墨镜、闭嘴微笑。
- 红色马甲：不再是圆筒。改为敞开的无袖马甲：前襟 V 形敞开露出白色内衬背心，宽袖口、粗肩带，下摆略微外扩且左右不齐，有口袋和纽扣、白色滚边；左右前片随身体运动轻微摆动。
- 草帽不再投下大片阴影，脸更亮。

### 3. 半蹲投掷
- 投掷模式右上角「姿势：站立 / 半蹲」切换。
- 半蹲：右膝跪在码头上、左脚在前，身体压低前倾；蓄力时更低更扭身，出手点贴近水面，随挥时右臂甩过身前。
- 物理：半蹲出手点更低、出手角度低 1°、最大力度为站立的 92%（打得更平，但略近）。

### 4. 岛上自由走动 / 跑步
- 手机：左下角浮动虚拟摇杆（手指在左下区域任意位置按下即出现），轻推走路、推到底跑步；单指在其它区域拖动转视角，双指捏合缩放。
- 电脑：WASD / 方向键走路，按住 Shift 跑步；鼠标拖动转视角，滚轮缩放。
- 走路 / 跑步为程序化步态：步频、步幅随速度变化，支撑脚与地面同速后移（不滑步），摆臂、身体前倾、上下起伏、骨盆扭转；跑步时腾空、屈臂。
- 跟随地形高度（沙滩、山坡、码头木板、码头台阶处可上下），碰撞椰子树、小屋、灯塔、礁石、木桩、木箱、篝火、躺椅、吊床等；不能走进深水，浅水可以蹚水（变慢、溅水花）。
- 脚步声随地面不同：沙地、木板、草地、浅水。
- 第三人称跟随相机：走动时慢慢转到身后，手指拖动可自由旋转；有简单的“弹簧臂”，相机不会穿进树干 / 小屋 / 道具。
- 右上角「观景」仍可进入 360° 观景模式。

### 5. 互动
- 椰子树间的吊床：走近后点「睡觉」→ 走到吊床边、转身坐下、躺进去；吊床轻轻摇晃，闭眼、呼吸起伏，草帽放在胸口，头上冒出「z Z z」。点屏幕或「起来」醒来。
- 沙滩毛巾（遮阳伞旁）：点「晒太阳」→ 坐下再躺倒，双手枕在脑后、脚踝交叉、戴墨镜、轻轻呼吸，草帽放在头边。
- 码头尽头（T 形平台）：点「打水漂」进入投掷模式（小男孩会走到平台前沿的空位）。**只有在这里才能扔石子**，岛上其它地方没有投掷按钮。
- 投掷模式里方向仍可任意调整（只会自动避开正对障碍物的方向）；扔完可以继续扔，或点「离开码头」回到自由走动。

### 6. 界面
- 竖屏和横屏分别布局：左下摇杆、右下动作按钮、右上「观景 / 声音 / 姿势 / 离开码头」。
- 竖屏使用单独的相机距离和视角，小男孩在画面里更大。

## 玩法速览
1. 点「点击开始」（松手时开启声音；iPhone 请关闭侧边静音开关）。
2. 用左下摇杆走到码头尽头，点「打水漂」。
3. 按住屏幕蓄力，左右拖转向、上下拖调角度，松手扔出；角度低、力度大才跳得多。右上角可切换站立 / 半蹲。
4. 「离开码头」后可以去吊床睡觉、去沙滩毛巾晒太阳。

## 目录
- `main.gd`：模式（自由走动 / 投掷 / 观景 / 休息）、移动与碰撞、相机、UI、声音、演示脚本。
- `boy.gd`：加载 `boy/boy.glb`，用 AnimationTree 混合动画片段（步态相位按移动距离推进）、表情、草帽 / 墨镜 / 石头道具。
- `art/boy/`：Blender 脚本——`build_boy.py`（建模 + 骨骼 + 衣服 + 道具）、`posekit.py`（IK 姿势工具）、`clips.py`（所有动画）、`export_boy.py`（AO 烘焙、动画烘焙、glTF 导出）、`test_*.py`（预览图）。
- `reflection.gd`：水面平面反射（镜像相机 + 低分辨率 SubViewport，按帧率自动降级）。
- `joystick.gd`：虚拟摇杆；`island.gd`：整岛程序化生成（含可摇晃的吊床、毛巾、行走碰撞体）；`mesh_builder.gd`；`shaders/`。
- `web/audio_unlock.js`：iOS 音频解锁脚本（压缩后写在 `export_presets.cfg` 的 head_include 中）。
- `tools/`：音效合成 / 检查、字体子集、浏览器（模拟 iPhone）测试脚本。
- `dev/boy_view.gd`：角色姿势检查；`dev/gait_probe.gd` + `dev/gait_view.gd`：步态检查（起步 / 走跑切换 / 转弯 / 之字形 / 急停，输出支撑脚每帧滑移量，`--csv=` 导出曲线，`--nolock` 关闭脚锁定对比）；`dev/selftest.gd`：回归测试（各动作结束后能否行走、走 / 跑是否对侧摆臂、投掷后是否回到待机）；均不会被导出。
- `docs/`：Web 导出结果（GitHub Pages 从这里发布）。
